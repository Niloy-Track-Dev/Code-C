# Contributing to C Code

First off, thank you for considering contributing to **C Code**! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
- Use the **GitHub Issues** tab.
- Describe the bug in detail and provide steps to reproduce.
- Include your device model and Android version.

### Suggesting Enhancements
- Open an issue with the tag `enhancement`.
- Explain why the feature would be useful.

### Pull Requests
- Follow the existing code style.
- Ensure your changes don't break the offline compiler engine.
- Update the documentation if you change any core functionality.

## Style Guidelines
- **Kotlin**: Follow the official [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html).
- **Compose**: Use Material 3 components and maintain edge-to-edge support.
- **Commit Messages**: Use descriptive, imperative-style commit messages (e.g., `feat: add support for math.h macros`).
